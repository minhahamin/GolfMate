- `SystemStatus.tsx` (`/`) — 백엔드/DB 연결 상태를 보여주는 Phase 1 확인용 페이지.

`/coach`, `/caddie`, `/courses`, `/courses/:id`, `/diary`, `/bet`, `/bet/:id`.
